Tệp phụ — file đã làm sạch và 3 khối dán tay

Chỉ cần khi muốn tự dán vào File báo cáo tổng. Nút Copy đưa dữ liệu vào clipboard, bấm đúng ô neo rồi Ctrl+V. Bản .xlsx là bản chuẩn, không mất kiểu dữ liệu.

Xem trước dữ liệu
Đối chứng với file tổng chuẩn

Nạp một bản đúng đã biết của ngày đang làm — ví dụ file do team làm tay hôm đó. Tool sẽ sinh file rồi so từng ô với bản đúng, chỉ ở những chỗ tool thực sự ghi. Các ô nhập tay không tính vào. Có kiểm tra thêm rằng lịch sử các ngày trước không bị đụng.

Cần đã bấm Xử lý và có nạp file tổng ở bước 1.
Tự kiểm chứng với dữ liệu mẫu

Nạp thêm 2 file kết quả mẫu trong Data/output/, tool chạy lại đúng pipeline rồi so từng ô. Dùng mỗi khi nguồn dữ liệu đổi định dạng.

Cấu hình ánh xạ

Luật lọc, ánh xạ cột, ô neo và bảng email. Lưu trong trình duyệt này. Khi web nguồn đổi tên cột thì sửa ở đây, không cần sửa code.
